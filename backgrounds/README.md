# Emerald Case backgrounds

This directory is reserved for the public wallpaper set.

Planned v0.1 assets:

- `lonely-road.jpg` — empty rural highway, dark plains and restrained emerald horizon glow.
- `rural-sky.jpg` — isolated farmhouse/roadside landscape under an emerald cosmic-noir sky.

The public set intentionally avoids official franchise logos, character likenesses, production stills, and recognizable prop reproductions.

The final release images will be 16:9, stripped of private metadata, visually checked for desktop cropping, and documented in `../MEDIA.md`.
