# Media provenance

Emerald Case is designed for public distribution as an Omarchy theme.

## Release artwork policy

Wallpapers included in the public repository should:

- be original or AI-assisted artwork created specifically for Emerald Case;
- avoid official HBO/DC/Warner Bros. logos and title treatments;
- avoid character likenesses and copied production stills;
- avoid reproducing distinctive franchise props as the primary subject;
- preserve the rural cosmic-noir direction through lighting, composition, color, weather, roads, fields, and environmental storytelling instead.

## Current assets

The first wallpaper set was generated specifically for this project with OpenAI image generation under user direction.

Before registry submission, every shipped image should be checked for:

- dimensions and file size;
- desktop crop behavior;
- metadata/privacy;
- redistribution suitability;
- visual consistency with the active palette.

The final `preview.png` must be a real screenshot of Emerald Case running in Omarchy, not a wallpaper mockup.
